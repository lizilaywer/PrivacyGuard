# Phase 3 — Word 文档接入识别引擎（双栏对比预览自动高亮）UI Design Contract

> Visual and interaction contract for Phase 3 — `privacyguard/pii/word_adapter.py` + Word 双栏对比预览 PII 自动高亮 + 工具栏「本文件使用全遮蔽」toggle。Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none（PyQt6 + QtWebEngine 桌面应用，无 shadcn / 第三方组件库） |
| Preset | not applicable |
| Component library | PyQt6 原生 widget + QWebEngineView 内嵌 HTML/CSS（双栏预览走 inline style + class） |
| Icon library | PyQt6 原生 `QStyle.StandardPixmap`（沿用 main.py 既有 `get_icon` 调用，无新增图标库） |
| Font | `'Segoe UI Variable', 'Segoe UI', 'Microsoft YaHei UI', 'Microsoft YaHei', Arial, sans-serif`（`theme.py::Theme.FONT_FAMILY`，Phase 3 零修改） |

> **Rationale:** Phase 3 是 desktop Qt 应用，不存在 React/shadcn/Tailwind 概念。所有视觉契约以 **Qt widget stylesheet + 双栏预览 inline CSS** 为落点，不引入新设计语言、不引入新字体、不引入新色系。

## Spacing Scale

Qt layout 内 spacing 与 HTML inline style padding 都按以下 4 倍数 token 收敛：

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 工具栏 toggle 控件内边距；tooltip 箭头与文字间距 |
| sm | 8px | 高亮 mark 上下 padding；列表项纵向间距 |
| md | 16px | 工具栏按钮水平间距；预览区段间垂直 padding |
| lg | 24px | 双栏左右栏间距；modal/sheet 边距 |
| xl | 32px | 主面板与子面板分隔 |
| 2xl | 48px | （保留）大段分隔；Phase 3 不强制使用 |
| 3xl | 64px | （保留）页面级；Phase 3 不强制使用 |

Exceptions:
- 高亮 mark 的 `padding` 走 `0 2px`（HTML 内联样式紧贴文字基线，避免影响段高）
- 工具栏 toggle 控件的最小命中区走 Qt 默认 22×22（不强制 44px，桌面端遵守 OS 习惯）
- tooltip 与目标高亮之间的间距走 6px（不上 8 倍数轴，保持视觉贴合）

## Typography

Qt 端（main.py / workers）与 HTML 端（QWebEngineView 双栏预览）共用以下三档：

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Qt 控件 / 段内文字 / 工具栏标签 |
| Label | 12px | 600 | 1.3 | tooltip 头部 / 高亮 mark `title` 属性 |
| Heading | 16px | 600 | 1.4 | 候选计数标签 / 工具栏 toggle 旁的实体类型标签 |

> **Font stack 锁定:** Qt 端走 `Theme.FONT_FAMILY`；HTML 端双栏预览走 `'Microsoft YaHei UI', 'Microsoft YaHei', 'Segoe UI', Arial, sans-serif`（与既有 cp27 修复点的预览内 font-family 一致，不引入 web font）。
> **Font weight 锁定:** 400（regular）+ 600（semibold）二档；不引入 700/800，避免视觉杂乱。
> **HTML 高亮 mark 内:** 继承段内 `font-family` / `font-size`；高亮自身不另设字号，仅设背景色 + 边框 + 圆角。

## Color

### 60/30/10 视觉分布

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF`（浅色）/ `#1E2836`（深色） | 主面板背景、QWebEngineView 双栏 preview 容器底色 |
| Secondary (30%) | `#F7F8FA`（浅色）/ `#151C26`（深色） | 工具栏、info bar、scroll area 底色 |
| Accent (10%) | `#D64545`（浅色）/ `#FF6B6B`（深色） | **仅用于 PII 命中在左栏（原文）的高亮边框 + mask 替换区底色**——见下文「Accent reserved for」 |
| Destructive | `#D64545`（浅色）/ `#FF6B6B`（深色） | 「本文件使用全遮蔽」toggle 激活态、`btn_mask_override` 文档级 toggle 激活态 |

### Accent reserved for（仅以下元素，绝不外溢）

1. **左栏（原文）PII 命中 mark 的 `border` 颜色** — `border: 1px solid #D64545;`
2. **左栏 PII 命中 mark 的 `box-shadow` 颜色** — `box-shadow: 0 0 0 1px rgba(214,69,69,0.25);`
3. **右栏（替换后）PII 命中区 mask 文本底色** — `background: rgba(214,69,69,0.12); border: 1px solid #D64545;`
4. **PII 高亮 mark 的 `outline`（focus 态）** — `outline: 2px solid #D64545;`
5. **工具栏「本文件使用全遮蔽」toggle 激活态边框** — 与 PDF 端 `btn_mask_override` 共用

### 与 PDF 端深红色一致性

- Phase 1 PDF 端 PII 自动识别用 `#d63031` 作高亮色；Phase 3 **不引入新色**，统一走 theme.py `danger` 槽 `#D64545`（浅色）/ `#FF6B6B`（深色）
- 跨格式识别结果在用户视觉认知中统一为「红色 = 自动识别的敏感项」，不出现「PDF 红 / Word 紫」分色
- HTML 高亮 mark 通过 CSS 变量而非硬编码，便于 Phase 7 切换主题时一处改全局生效

### OCR / rule / manual 三类既有高亮的色槽（Phase 3 零修改）

| Source | 颜色（浅色） | 颜色（深色） | 来源 |
|--------|-------------|-------------|------|
| ocr | `#FFEB3B`（黄底） | `#FFD54F` | 既有 `ocr-highlight` class，Phase 3 不改 |
| rule | `#A5D6A7`（绿底） | `#81C784` | 既有 `rule-highlight` class，Phase 3 不改 |
| manual | `#90CAF9`（蓝底） | `#64B5F6` | 既有 `manual-highlight` class，Phase 3 不改 |
| **pii**（新增） | `#D64545`（红底 + 红边框） | `#FF6B6B`（红底 + 红边框） | `pii-highlight` class，D-01 扩展源 |

### 1. 新增 QWebEngineView HTML 类（双栏预览 PII 高亮）

| 类名 / 入口 | 文件 | 职责 |
|------------|------|------|
| `.pii-highlight` CSS class | `theme.py` 或 `main.py:_get_word_preview_css` | 左栏（原文）PII 命中 mark 的样式 |
| `.pii-mask-highlight` CSS class | 同上 | 右栏（替换后）PII mask 替换区的样式 |

CSS 规格（直接落入 Qt 端 `setHtml` 的 `<style>` 块，cp27 修复点附近）：

```css
/* 左栏原文 PII 高亮（与 PDF 端 PII 同色 #D64545 / #FF6B6B） */
.pii-highlight {
    background: rgba(214, 69, 69, 0.12);
    border: 1px solid #D64545;
    border-radius: 3px;
    padding: 0 2px;
    cursor: help;
    box-shadow: 0 0 0 1px rgba(214, 69, 69, 0.18);
}

/* 深色主题（dark mode） */
[data-theme="dark"] .pii-highlight {
    background: rgba(255, 107, 107, 0.15);
    border-color: #FF6B6B;
    box-shadow: 0 0 0 1px rgba(255, 107, 107, 0.22);
}

/* 右栏替换后 PII mask 区 */
.pii-mask-highlight {
    background: rgba(214, 69, 69, 0.08);
    border: 1px solid #D64545;
    border-radius: 3px;
    padding: 0 2px;
    font-weight: 600;
}

[data-theme="dark"] .pii-mask-highlight {
    background: rgba(255, 107, 107, 0.10);
    border-color: #FF6B6B;
}

/* Focus / hover 态 */
.pii-highlight:hover,
.pii-highlight:focus {
    outline: 2px solid #D64545;
    outline-offset: 1px;
}
```

### 2. 工具栏「本文件使用全遮蔽」toggle

| 控件 | 文件 | 复用 / 新增 | 视觉契约 |
|------|------|------------|---------|
| `btn_mask_override` | `main.py`（既有 PDF 端 5896-5901） | **复用同一 widget** | D-05 决策：与 PDF 共用；视觉上紧邻摆放，控件不复制 |
| `self._word_mask_override_this_doc` | `main.py`（独立字段，**新增**） | 新增 | Phase 3 改为独立字段而非 `word_data[0][...]`，避免 word_data 业务键空间污染（research.md Open Question #1 已 raise） |

- tooltip：见上「Copywriting Contract」
- toggle 触发时写 `self._word_mask_override_this_doc = "blackout" | "partial"`，**不** 写 word_data 业务键
- `MainWindow._save_word` 调用 `apply_pii_replacements_to_docx` 时按 `self._word_mask_override_this_doc` 决定 `mode` 形参（默认 `"partial"`）
