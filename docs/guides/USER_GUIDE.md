# PrivacyGuard 脱敏卫士 — 用户使用手册

> 版本：v37.8.11　|　更新日期：2026-08-02　|　适用对象：终端用户（法律/文秘/档案等非技术岗位）

PrivacyGuard 是一款桌面脱敏工具，用于对 PDF 与 Word 文档中的个人隐私、商业敏感信息进行
智能识别与遮盖（脱敏），并安全导出。本手册面向实际使用者，按"想做什么 → 怎么操作"组织。

## 1. 它能做什么

| 能力 | 说明 |
|------|------|
| PDF 智能脱敏 | 自动识别身份证、手机号、银行卡等 12 类敏感信息并遮盖；支持图片型 PDF 的 OCR 识别 |
| 手动框选脱敏 | 对自动漏识别或需特别处理的区域，手动画框遮盖 |
| 整文档定向遮罩 | 输入关键词，对全文中所有匹配内容一次性遮盖 |
| 印章/签名/手印检测 | 自动识别红色印章、手写签名与按手印区域（带暖色门控，避免误遮彩色正文） |
| Word 脱敏 | 对 .doc/.docx 按规则、关键词或批量方式替换敏感内容 |
| 双预览对照 | Word 左原文、右脱敏后对照，高亮可按来源（规则/手动/OCR）筛选 |
| 全文搜索 | 跨页搜索关键词，点击定位并闪烁高亮 |
| 页面管理 | 多页网格概览、缩放、旋转、插入、删除页面 |
| 加密导出 | AES-256 加密导出 PDF，可设置打开/编辑密码 |
| 脱敏报告 | 导出时生成规则分类汇总 + 逐页明细，可存 txt |
| 会话恢复 | 异常退出后可恢复未完成的脱敏草稿 |
| 痕迹清理 | 一键清理草稿、临时文件、预览缓存、日志 |

## 2. 安装与启动

### 打包版（推荐普通用户）

1. 获取对应平台的安装包（Windows / macOS）。
2. Windows：解压后双击 `PrivacyGuard.exe` 启动；macOS：将应用拖入"应用程序"后启动。
3. 首次启动会从模板生成本地配置文件 `config.json`（位于用户目录，已自动忽略上传）。

### 源码运行（开发者）

需要 Python 3.11+ 与项目虚拟环境：

```powershell
# Windows
.\venv_win\Scripts\python.exe main.py
# macOS
./venvmac/bin/python3 main.py
```

> 依赖说明：OCR 功能依赖 `rapidocr-onnxruntime`，首次执行 OCR 时才初始化（懒加载），
> 缺失时不影响打开文档与规则扫描等非 OCR 功能。

## 3. 快速上手（5 分钟完成第一次脱敏）

1. 启动程序，点击工具栏"打开"按钮（或拖拽文件到窗口），选择一个 PDF。
2. 文档加载后，点击工具栏"扫描"按钮开始智能识别。
3. 扫描完成，识别到的敏感信息会以遮罩框显示在页面上。
4. 检查遮罩是否符合预期：
   - 漏识别：用鼠标在对应区域手动画框补遮。
   - 误识别：在遮罩列表中删除该条，或撤销（Ctrl+Z）。
5. 确认无误后，点击"导出"，选择保存位置。
6. （可选）导出时勾选加密并设置密码，或勾选生成脱敏报告。

> 提示：第一次使用建议保持默认规则与扫描设置，熟悉后再到"设置中心"调整。

## 4. PDF 脱敏

### 4.1 打开文档

- 工具栏"打开"按钮，或直接将 PDF 拖入窗口。
- 支持 .pdf 格式。

### 4.2 规则扫描（12 类预设规则）

点击"扫描"后，程序按勾选的规则自动识别并遮盖。预设规则如下（可在设置中心开关）：

| 规则 | 说明 | 校验 |
|------|------|------|
| 身份证号 | 18 位（含校验位 X）与 15 位旧版，含省级前缀与年月日结构校验 | 结构校验 |
| 手机号码 | 1 开头 11 位 | — |
| 日期时间 | 年-月-日 / 年.月.日 / 年月日 | — |
| 电子邮箱 | 标准邮箱格式 | — |
| 银行卡号 | 13–19 位 | Luhn 校验位 |
| 统一社会信用代码 | 18 位（不含 IOZSV） | mod 31-3 校验 |
| 车牌号 | 省份简称+字母+5 位（普通）/ 6 位（新能源） | — |
| 固定电话 | 区号+7-8 位号码，可选分机 | — |
| 护照号 | E/G/D/S/P + 8 位 | — |
| 港澳台通行证 | C/W + 8 位 | — |
| 车架号 VIN | 17 位（不含 IOQ） | 第 9 位校验 |
| IP 地址 | IPv4 四段 | 范围校验 |

> 带校验位的规则会做二次验证，不满足校验位的数字串（如案件号、统计号）不会被误遮。

### 4.3 印章 / 签名 / 手印检测

- **印章检测**：自动识别红色圆形/椭圆形印章区域。
- **签名手印检测**：自动识别手写签名与按手印区域。
- 二者均带"暖色门控"：只处理印章/手印的典型暖色调，不会误遮正文中的彩色文字。
- 在设置中心可单独开关这两项检测。

### 4.4 图片型 PDF 的 OCR 识别

- 对扫描件、图片型 PDF，程序自动调用 OCR 识别图中文字，再按规则脱敏。
- 混合型 PDF（既有文本层又有图片块）会分别处理文本层与图片块，OCR 结果按局部坐标回填到页面。
- OCR 首次运行需加载模型，稍慢；后续会话内有缓存。

### 4.5 手动框选脱敏

- 对自动识别遗漏或需特别处理的区域，在页面上按住鼠标拖动画框，即可手动遮盖。
- 手动遮罩与规则遮罩用不同方式区分，可在遮罩列表中单独删除。

### 4.6 整文档定向遮罩

- 当你想遮盖某个人名、单位名、案号等不在预设规则里的内容时：使用"定向遮罩"功能，
  输入关键词（多个用空格分隔），程序对全文中所有匹配位置一次性遮盖。
- 适合处理"原告张三"这类需要全文统一遮盖的固定内容。

## 5. 页面视图操作

### 5.1 多页网格概览

- 默认多页网格显示，可一览全部页面缩略图。
- 工具栏可切换显示模式。

### 5.2 缩放

- **Ctrl + 鼠标滚轮**：列数缩放，松开滚轮到边界时有阻尼回弹。
- **适合页面**：从任意视图回到单页适合显示。

### 5.3 页面选择

- **单击**：选中一页。
- **Ctrl + 单击**：多选（不连续）。
- **Shift + 单击**：范围选择（连续多页）。

### 5.4 页面编辑

- **旋转**：旋转选中页面（遮罩随之变换坐标，不会错位）。
- **插入**：在指定位置插入页面。
- **删除**：删除选中页面。
- 所有页面结构操作均支持撤销/重做，并纳入会话草稿。

### 5.5 遮罩颜色

- 可即时切换遮罩颜色（如黑色/白色块），无需重新扫描。

## 6. 全文搜索定位

- 点击工具栏"放大镜"按钮打开搜索侧栏。
- 输入关键词，程序跨页搜索：
  - 文本型 PDF：直接搜文本层。
  - 扫描件：对页面做 OCR（带会话缓存，二次搜索更快）后搜。
  - Word：按段落块搜索。
- 搜索结果点击即可定位到对应位置，并以闪烁高亮提示（词级/行级）。

---

## 7. 撤销与重做

- **Ctrl + Z**：撤销上一步（遮罩编辑、页面结构操作均可撤销）。
- **Ctrl + Y**：重做。
- 撤销栈深度 20 步；删除页面等结构性操作通过文档快照完整恢复。

## 8. 导出与加密

### 8.1 导出脱敏后的 PDF

- 点击"导出"，选择保存位置即可。遮罩会被"烧录"到导出的 PDF 中，无法还原。

### 8.2 加密导出（AES-256）

- 导出时可勾选加密，设置：
  - **打开密码**：打开 PDF 需输入。
  - **编辑密码**：修改 PDF 需输入。
- 加密强度 AES-256。

### 8.3 脱敏报告

- 导出时可生成脱敏报告，包含：
  - 规则分类汇总（各规则命中条数）。
  - 逐页明细（每页遮盖了哪些内容）。
- 报告可导出为 txt 文件留存。

## 9. Word 脱敏

### 9.1 打开 Word 文档

- 支持 .doc 与 .docx（.doc 会自动转换为 .docx 处理）。

### 9.2 规则替换

- 与 PDF 共用 12 类预设规则，对 Word 正文中的敏感信息按统一替换文本替换。
- 替换文本默认 `[已脱敏]`，可在设置中心修改。

### 9.3 自定义关键词

- 在设置中心"自定义关键词"区，每行一个关键词。
- 支持 `关键词|替换文本` 格式指定专属替换文本（如 `原告|上诉人`）。
- 不带 `|` 的行使用统一替换文本。
- 支持从 JSON 文件导入/导出关键词规则。

### 9.4 Word 替换规则设置

- 比"自定义关键词"更高级：支持精确匹配与正则匹配，优先级最高。
- 可在"替换规则设置"弹窗中维护、导入、导出。

### 9.5 批量替换

- 对多个 Word 文件套用同一套规则一次性处理，适合卷宗批量脱敏。

### 9.6 双预览与高亮筛选

- 左侧原文、右侧脱敏后对照显示。
- 高亮可按来源筛选：**规则 / 手动 / OCR**，便于核对不同来源的脱敏结果。

## 10. 设置中心

打开"设置"后，左侧导航切换不同区块（根据当前打开的文档类型，不相关的区块会自动隐藏）：

| 区块 | 作用 |
|------|------|
| 通用规则 | 开关 12 类预设规则；恢复推荐勾选 / 全选 / 清空 |
| 自定义关键词 | 维护关键词列表，支持 `关键词\|替换文本`；导入/导出 JSON |
| Word 替换规则 | 精确/正则匹配规则，优先级最高；导入/导出 |
| 扫描精度 | 扫描级别、横向/宽度偏移微调、增强开关 |
| OCR 检测框调节 | 滑块调节 OCR 检测框大小比例（百分比） |

- 顶部概览显示当前规则数、关键词数、Word 规则数、OCR 调节值。
- 保存设置后，关键项重启仍生效；OCR 调节等为会话级，UI 会明确说明。

## 11. 会话恢复（草稿）

- 程序会为进行中的脱敏工作自动保存草稿（含遮罩进度与文档结构快照）。
- 异常退出（崩溃/断电）后再次启动，可恢复未完成的脱敏进度，避免重来。
- 草稿采用崩溃安全写入。

---

## 12. 痕迹清理

- 工具栏"痕迹清理"可一键清理：
  - 脱敏草稿
  - 临时文件
  - 预览缓存
  - 日志
- 清理带白名单路径保护，只清规定目录，不会误删用户文档。

## 14. 常见问题

**Q：扫描后有些身份证号没被遮住？**
A：身份证规则带省级前缀与年月日结构校验，不合规的数字串（如某些旧版、特殊地区码）可能被跳过。可用"定向遮罩"或手动框选补遮。

**Q：银行卡号把案件编号也遮了？**
A：银行卡规则带 Luhn 校验，正常案件号不会满足 Luhn。若仍误遮，可在设置中心临时关闭"银行卡号"规则，或删除该条遮罩后撤销。

**Q：图片型 PDF 扫描很慢？**
A：首次 OCR 需加载模型。同一会话内重复搜索/扫描有缓存，二次会快。大文档建议分批处理。

**Q：导出的 PDF 别人打不开？**
A：若设置了打开密码，对方需输入密码。确认密码已正确告知，或重新导出不加密版本。

**Q：Word 的 .doc 打不开？**
A：.doc 会自动转换为 .docx，需系统支持转换。若失败，建议先用 Word 另存为 .docx 再处理。

**Q：误删了页面怎么恢复？**
A：立即 Ctrl+Z 撤销即可恢复（删除页面有完整文档快照）。若已关闭程序，可从会话草稿恢复（前提是该次操作前的草稿已保存）。

**Q：印章被漏识别？**
A：印章检测针对典型红色圆形印章。非标准颜色/形状的印章可能漏识别，可手动框选补遮，或在设置中心确认"印章"检测已开启。
