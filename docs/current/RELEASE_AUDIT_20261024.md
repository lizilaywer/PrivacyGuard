## 当前架构与功能理解

### 分层

`main.py` 管理 SimpleConfig、窗口、模式与状态，继承 PageView / WordPreview / SettingsActions / Crop / Extract / Bookmark mixin；业务算法在 `privacyguard`。
新代码继续采用独立纯函数/Worker/面板，不把大段算法塞回 MainWindow。

- `ocr/text_pdf.py`：文字层规则搜索、银行卡 Luhn、USCC/VIN 等校验、文字框与旋转坐标。
- `ocr/mixed_pdf.py`：发现嵌入图块→裁剪渲染→OCR→子串定位→局部坐标加图块原点；不是把混合页粗暴判成纯文字页。
- `workers/ocr_worker.py`：后台编排文字层/图块/印章/签名，逐页发射矩形；称谓识别共享名称集、结束后回填前页。
- `utils/helpers_word_*`、WordWorker/BatchReplaceWorker：文本块偏移、规则优先级、run 级替换、批量统计；Word 的核心是替换，不是 PDF 的图形遮罩。
- `ui/mixins/word_preview_mixin.py` 与 `assets/js`：mammoth 转 HTML、data-key 映射、DOM 增量更新、双栏联动与高亮来源过滤；WebChannel 桥接手工脱敏。
- `ui/panels`：提取侧面板、书签侧面板独立 QWidget，信号与主窗口接线。
- `session_store.py`、`trace_cleaner.py`：恢复草稿与结构快照、受限范围清理；不是用户原文件备份服务。

## 仍需改善的明确问题（没有掩盖）

### P1：Word 的“全文”尚不覆盖所有 OOXML 内容

- 已实测：超链接可见文字在 `para.text`，却不在 `para.runs`；当前 `paragraph_plain_text` 为保持替换偏移同源故只取 runs，超链接内 SECRET_LINK 不进入扫描。
- 已实测：单元格内嵌套表格的 SECRET_NESTED 在批量替换中计数为 0。顶层表格遍历不是递归遍历。
- Word 图片只是预览/原样保留，不做图像 OCR 脱敏。批注、修订删除文字、文本框、脚注尾注、文档属性、关系目标亦未纳入通用全包清除。
- 不能靠“把 para.text 改回来”临时补洞：这会再次引入超链接偏移错位，必须同步设计文本→XML run 的映射、递归表格 key、预览/扫描/保存/批量共用遍历。
- 对含上述特殊内容的敏感文件，当前包应视为辅助工具，必须人工复核；本轮没有冒充已完成这项跨模块改造。

### P1/P2：PDF 导出不是全面文件净化器

- 当前 save_pdf 对命中区执行物理 redaction 并删除页面注释，但没有对作者/XMP、嵌入附件、全部表单值/动作做统一清除。
- 因此“区域内容已销毁”不等于“文件内所有敏感载荷均不存在”；正式外发敏感卷宗前应单独检查附件、属性、表单和书签。
- 提取是文档编排功能，源工作台遮罩不会自动烘焙进提取结果。应对提取结果“回炉打开”再执行脱敏，不能误把左侧的遮罩当作右侧已生效。

### P2：搜索、识别与性能后续

- DocSearchWorker 遇到有文字层的页就直接 continue，因此混合页图像内的文字可能搜不到；正文脱敏的 mixed_pdf 管线不受此限制。
- 自定义称谓表在正向匹配有效，但反向“姓名+作为/担任/系+称谓”默认仍使用内置表；需要把 titles 契约贯通三管线。
- 称谓算法的“3/3=100%”只是某份 16 页样本，不代表通用准确率；少数民族中间点姓名、罕见汉字、跨行/误识别内容都需要更大的标注集。
- 超大 Word 的 ZIP 解析/mammoth/HTML 建模仍在主线程；多页网格虽分帧渲染，仍一次创建所有页卡。下一阶段应独立做可取消的文档准备 Worker 和虚拟化页卡。
- 用户正则没有执行超时，复杂表达式可能耗时；不应接受未经审核的外部规则集。
- 会话快照/解密临时文件虽权限受限，仍为明文，异常断电会遗留；高敏感场景应退出后清理痕迹，并使用系统磁盘加密。

## 验证结果

- 起始基线：715 discovered，713 passed，2 skipped。
- 修复后：730 discovered，728 passed，2 skipped；新增 15 项针对性测试。跳过的两项依赖仓库未提供的真实印章/手印样本，合成样本用例正常执行。
- Ruff（main.py/privacyguard/tests）、compileall、pip check、shell 语法检查通过。
- 当前机器合成基准：1,500 段落批量替换 1,500 处约 0.117 秒；50 页安全矢量提取约 0.087 秒。仅作为本机基线，不是任意大文档承诺。
- 源码原生 Cocoa 自检通过。沙箱离屏 WebEngine 曾 abort，改用原生 Cocoa 验证，未把失败隐藏成成功。
- ZIP 解压后的冻结应用自检通过：XML、Decimal、含图 DOCX 转换/应用内打开/替换保存、矢量提取原始流检查、真实离线 OCR（禁止 socket.connect）、版本与主窗口关闭。
- 正常启动入口也已执行，进程保持运行；日志写用户目录。启动/自检后再次 codesign 与全包验证通过，包内没有生成 config.json/log。
- GUI 自动化连接超时，未获得真机截图；未宣称逐像素视觉验收。未在 macOS 14 真机或 Intel Mac 运行，14.0 是二进制静态门禁结果。
- Windows 本轮仅源码与 spec/生成版本资源同步，未在 Windows 重打包或真机运行。
